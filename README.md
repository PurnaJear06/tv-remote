# tv-remote

A personal web remote for my own Samsung TV at home. It's not a supported project.

- It runs entirely in the phone's browser and talks straight to the TV over home Wi‑Fi. No server, cloud or account is involved.
- It only works on my home network, and only after the phone is approved with **Allow** on the TV itself.
- The pairing token is stored only on each phone, never in this repo.
